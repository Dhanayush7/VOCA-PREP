# VOCA-PREP

A minimal browser prototype of an AI mock interview flow:

- Choose an interview track (Frontend, MERN, C++/DSA, HR, Full Stack)
- Answer AI questions with a simulated Sarvam Speech-to-Text step
- Receive per-answer evaluation (technical accuracy, completeness, communication)
- Continue with follow-up questions
- Get a final interview report with strengths and improvement areas

## Run locally

Open `/home/runner/work/VOCA-PREP/VOCA-PREP/index.html` in a browser.
